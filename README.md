# OriPet

[English](#english)

OriPet 是面向 Windows 的非官方《奥日》桌面宠物。

> 本项目是非商业性质的同人作品，与 Moon Studios、Microsoft 或 Ori 系列的其他权利方不存在官方关联。

## 项目版本

### OriPet 1.0

使用 Qt 5 开发的原型版本，完成了桌面宠物的基本交互与动作系统。

演示视频：[哔哩哔哩](https://www.bilibili.com/video/BV1Ce2vY8Eus)

### OriPet 2.0+

使用 Unity 开发的新版本，目前仍处于测试阶段。

新版本重新设计了角色控制、动画、桌面环境交互和自主行为系统，并将继续加入更多动作与功能。

## 问题反馈

如果在使用过程中遇到问题，可以通过本仓库的
[Issues](https://github.com/LightRill/OriPet/issues) 进行反馈。

提交问题时，建议附带：

- 使用的 OriPet 版本
- Debug 版本内 Diagnostics 日志文件
- 问题发生前后的操作
- 屏幕录制或截图
- 问题是否可以稳定复现

## English

OriPet is an unofficial _Ori_-themed desktop pet for Windows.

> This is a non-commercial fan project and is not affiliated with Moon Studios, Microsoft, or any other rights holder of the _Ori_ series.

## Versions

### OriPet 1.0

The original prototype was developed with Qt 5 and provides the basic desktop interaction and movement systems.

Demo video: [Bilibili](https://www.bilibili.com/video/BV1Ce2vY8Eus)

### OriPet 2.0+

A new version developed with Unity, currently under testing.

This version redesigns the character controller, animation system, desktop-environment interaction, and autonomous behavior system. More actions and features will be added in future versions.

## Feedback

If you encounter a problem, please report it through this repository's
[Issues](https://github.com/LightRill/OriPet/issues).

When reporting an issue, please include:

- OriPet version used
- Diagnostics log file from the Debug version
- Actions performed before and after the issue occurred
- Screen recording or screenshots
- Whether the issue can be consistently reproduced

## Repository Scope

Character, animation, visual, and audio assets used by OriPet originate from or are modified from the _Ori_ series. All related rights belong to their respective owners. These assets may not be reused in other projects or for commercial purposes without permission.
